Current pills

Rounded capsules, copper active fill, type-aware hover. Familiar, production-shipped, mobile-safe (44px).

+ Already shipped; zero migration cost.

− Capsules read as generic SaaS chips, not coffee-ledger language. Competes with the corkboard for roundness.

Ledger Index RECOMMENDED

Sharp corners, indexed numerals, ink rule under the active entry. No fills — structure from rules, per the Coffee Ledger Rule.

+ Reinforces the ledger identity; cheapest ink budget; scales to long sort lists; reads at small sizes.

− Lowest chroma — type-aware color is subtle. Needs the bottom rule to read as a control, not plain text.

Stamp Tags

Dashed border, punched-hole dot, active state tilts like an inked rubber stamp. Most tactile of the four.

+ Strongest craft personality; matches the stamp progress cues already in the app.

− Rotation can feel busy across a full row; dashed inactive border adds visual noise on dense recipe filters.

Folder Register

Kraft manila-tab shape, lifted when active, baseline rule like a folder spine. Most literal paper metaphor.

+ Very tactile; active tab “lifts” clearly; kraft texture ties to the corkboard.

− Trapezoid clip-path is fragile at small sizes and on the sort row; tabs need a shared baseline rule or they float. Heaviest to implement.
