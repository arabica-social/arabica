# Feature Decision Records

Feature Decision Records describe the current user-visible behavior of an
implemented or experimental feature and the non-obvious product decisions that
shape it.

FDRs are living current-state documents: rewrite behavior when a feature
changes rather than appending changelog notes. Proposed features and unresolved
choices remain in [`docs/plans/`](../plans/). Cross-cutting technical rationale
belongs in [`docs/adr/`](../adr/INDEX.md).

Use [`TEMPLATE.md`](TEMPLATE.md) for new records.
